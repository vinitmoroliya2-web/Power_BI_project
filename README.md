# Power_BI_project
Motorola Sales Analysis | Power BI Dashboard

An interactive dashboard analyzing $769M+ in sales across 19K units and 4K transactions.
KPIs: Tracked sales, volume, and Average Order Value.

Trends:Monthly/quarterly seasonality and peak demand.

Insights:Geo-sales and payment habits.

UX: Dynamic filters for self-service BI.
Built with Power BI & DAX.
